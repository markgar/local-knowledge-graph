# Security Policy

## Supported versions

Until the first stable release, security fixes are provided on the latest
version of the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Security advisories** page for this repository to report it privately.

Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. Please allow maintainers reasonable time to investigate
before public disclosure.
